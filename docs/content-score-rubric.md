# Content Score Rubric v1

Canonical scoring spec for every blog generated by Pulse. Total = 100.
Target ≥ 80 to ship. Goal 90+.

Changes to weights, formulas, or thresholds require a version bump here
AND in the prompts that reference them (`prompts/scoring/*`).

## 1. Brand Alignment (20 pts)

**Inputs**: `brand_positioning` (mission, value_proposition, differentiators, topics_to_cover, topics_to_avoid, competitors), `brand_voice` (tone, audience, do_list, dont_list), post `title` + `content`.

**Deterministic pre-check**:
- For every entry in `topics_to_avoid`, search `title + content` case-insensitively. One or more matches caps the sub-score at **−5** (hard cap, applied after the AI rating).

**AI rating** (Claude, 0–20, four sub-criteria):
| Sub-criterion | Max | What Claude rates |
|---|---|---|
| Topic fit | 5 | How closely the post sits inside `topics_to_cover` — 5 = dead center, 0 = tangential/off-brand |
| Differentiator presence | 5 | Does the post name or demonstrate ≥1 `differentiators` naturally — 5 = clearly, 0 = not at all |
| Voice match | 5 | Matches `brand_voice.tone` + follows `do_list` / avoids `dont_list` — 5 = indistinguishable from example posts, 0 = completely off |
| Avoids banned topics | 5 | 5 if zero matches on `topics_to_avoid`; 0 if multiple |

**Flag threshold**: < 16 → issue with severity `high`, message identifying the weakest sub-criterion.

## 2. SEO Fundamentals (20 pts)

Fully deterministic. Inputs: `title`, `meta_description`, `target_keyword`, `secondary_keywords`, `content`, `outline`, `slug`.

| Check | Pts | Rule |
|---|---|---|
| Title length | 3 | 50–60 chars = 3, 45–65 = 2, 40–70 = 1, else 0 |
| Meta description length | 3 | 140–160 chars = 3, 130–170 = 2, 120–180 = 1, else 0 |
| Target keyword placement | 5 | 1 pt each for presence in: title, first H1, first 100 words, any H2, conclusion section |
| Keyword density | 3 | (keyword_count / word_count × 100) in [0.5, 2.5] = 3; 0.3–0.5 or 2.5–3.5 = 2; else 0 |
| Secondary keywords used | 3 | ≥ 2 of `secondary_keywords` appearing in body = 3; 1 = 1; 0 = 0 |
| URL slug | 3 | ≤ 75 chars, all lowercase, hyphenated (no `_` / spaces / `%`), includes part of the target keyword = 3; meets length+format but no keyword = 2; else 0 |

**Flag threshold**: < 16. Emits one issue per failed check with `suggestedFix` (e.g. "Title is 72 chars — trim to 50–60").

## 3. Readability (15 pts)

Fully deterministic. Input: plain-text extracted from markdown (code blocks stripped).

| Check | Pts | Rule |
|---|---|---|
| Flesch Reading Ease | 8 | 60–80 = 8; linear falloff outside: 50–60 or 80–85 → 5–7; 40–50 or 85–90 → 2–4; <40 or >90 → 0 |
| Avg sentence length | 3 | 14–20 words = 3; 10–14 or 20–25 = 2; 6–10 or 25–30 = 1; else 0 |
| Avg paragraph length | 2 | ≤4 sentences = 2; 5 = 1; ≥6 = 0 |
| Passive voice rate | 2 | <15% = 2; 15–25% = 1; ≥25% = 0 (heuristic: count `(is/was/were/been/being) + past-participle` patterns) |

**Flag threshold**: < 11.

## 4. Depth & Originality (15 pts)

Hybrid.

**Deterministic** (6 pts):
- Word-count band hit (3): actual within ±10% of `target_word_count` = 3; ±10–15% = 2; ±15–25% = 1; else 0
- Specificity density (3): count of digits + proper nouns per 500 words ≥ 8 = 3; 5–8 = 2; 2–5 = 1; else 0

**AI** (9 pts):
Claude is given the post + top SERP results (when available from a recent `serp_analyses` row for the target keyword) and rates:
- Does this say something the top 10 don't already say? (6 pts: 6 = genuinely original angle, 0 = total rehash)
- Does it lean on `value_proposition` + `differentiators`? (3 pts)

If SERP context is missing, Claude rates originality against "what a reader would find in a generic top-10 search" — still 9 pts.

**Flag threshold**: < 11. Issues always include the AI-generated "what's already being said" note so the user sees the angle they missed.

## 5. Structure (10 pts)

Fully deterministic. Inputs: `outline`, rendered markdown headings/lists.

| Check | Pts | Rule |
|---|---|---|
| H1 unique | 2 | Exactly one H1 = 2; multiple or none = 0 |
| ≥3 H2 sections | 2 | 3+ = 2; 2 = 1; <2 = 0 |
| No H3 before H2 | 1 | If every H3 follows an H2 = 1; else 0 |
| At least one list or table | 2 | `- `, `* `, `1. `, or `|` present = 2; else 0 |
| Intro ≤150 words | 1 | First paragraph ≤ 150 = 1; else 0 |
| Conclusion section | 2 | Last H2 matches /conclusion|wrap.?up|final|summary|takeaways/i = 2; else 0 |

**Flag threshold**: < 7.

---

## 6. FAQ Schema (10 pts)

Fully deterministic. Inputs: FAQ block(s) in `content`, `faq_schema` jsonb if populated.

| Check | Pts | Rule |
|---|---|---|
| ≥3 Q/A pairs present | 4 | 3+ = 4; 2 = 2; 1 = 1; 0 = 0 |
| Each answer 40–300 chars | 2 | All Q/A answers in range = 2; one outside = 1; multiple = 0 |
| Valid JSON-LD FAQPage | 2 | `faq_schema["@type"] === "FAQPage"` with populated `mainEntity` = 2; present but malformed = 1; missing = 0 |
| Questions phrased as questions | 2 | All questions end with `?` = 2; most = 1; few/none = 0 |

**Flag threshold**: < 7. Issues include "Add FAQ schema markup" with auto-generate action.

---

## 7. E-E-A-T (10 pts)

Hybrid.

**Deterministic** (6 pts):
- Outbound authoritative links (3): ≥2 links to `.gov`, `.edu`, or recognized-authority domains = 3; 1 = 2; 0 = 0. Authority list starts with: `wikipedia.org`, `nytimes.com`, `reuters.com`, `bbc.co.uk`, `ft.com`, `hbr.org`, `mit.edu`, `.gov`, `.edu`. Editable.
- Data citations (2): ≥1 inline citation pattern (`[source: …]` or `according to …`) = 2; else 0
- Author byline (1): post metadata includes an `author` field = 1; else 0

**AI** (4 pts):
Claude rates expertise signals:
- Specificity (2): specific examples, jargon used correctly, not generic blogspeak
- Hedging (2): appropriately uncertain where it should be (e.g. trends, projections)

**Flag threshold**: < 7.

## Auto-iterate contract

In `generate-blog-post.ts`:

```
pass = 1
while pass <= 3:
  if pass == 1: generate()
  else: refine(previous_draft, filter(issues, severity in ["high","med"]))
  while word_count off > 10% (max 2 expansions): expand()
  score = scoreBlogPost()
  if score.total >= 80: return { draft, score, warning: false }
  pass += 1
return { draft, score, warning: true }   # score_warning flag in DB
```

Cost cap: if `generation_meta.total_cost_usd > $0.25`, early-exit with
warning. Recorded in `generation_meta.stopped_reason`.

Low-severity issues are carried forward to refine passes as
informational only — they don't drive rewrites.
